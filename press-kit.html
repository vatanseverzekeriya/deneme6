📋 Game Overview

RPG Mobile is a browser-based, mobile-optimized RPG game inspired by Metin2. Players choose from 4 unique character classes, battle monsters, level up, and collect loot. Built with vanilla JavaScript and Canvas 2D, the game runs smoothly on all devices without any downloads.

✨ Key Features

  • 4 Unique Character Classes: Warrior, Ninja, Shaman, Sura - each with distinct abilities
  • Full Mobile Support: Touch controls, joystick movement, optimized UI
  • Progressive Difficulty: 5+ enemy types that scale with player level
  • Real-time Combat: Fast-paced action with cooldown-based skills
  • Loot System: Collect potions, weapons, and armor from defeated enemies
  • Leveling System: Gain XP, level up, increase stats
  • Optimized Performance: 60 FPS target with advanced rendering optimizations
  • No Installation: Play directly in browser - works on all devices
  • Live Reload: Instant updates during development

⚡ Performance Optimizations

  • Grid Caching: Background rendered once to offscreen canvas
  • Viewport Culling: Off-screen objects don't render
  • Object Pooling: Mobs and drops reused to reduce garbage collection
  • Font Caching: Pre-calculated font strings for better performance
  • Delta Time: Frame-rate independent movement and updates
  • FPS Throttling: Capped at 60 FPS for consistent performance
  • Batch Rendering: Optimized draw call batching
  • Shadow Optimization: Simplified shadow effects for mobile
